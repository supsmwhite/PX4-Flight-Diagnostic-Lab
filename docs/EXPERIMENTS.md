# 实验规范与验证路线

## 范围和状态

本文件是可复现实验设计，不是已完成试验报告。实际执行结果以 [PROGRESS.md](../PROGRESS.md) 为准。当前工程没有实机验证声明，不负责决定起飞条件，不进行控制闭环、ULog 根因分析或飞行安全认证。

仅分析已有数据不会证明原始数据正确；合成 MAVLink、回环 UDP、台架遥测与实机飞行是四个不同证据等级，报告必须标明。任何真实设备试验先征得现场负责人同意；默认无桨台架或离线输入，操作和遥控接管由人员负责。

## 每次实验必须记录

- 研究问题、待检验假设、替代解释、成功/失败判据；不能先认定故障原因再筛数据。
- 工具版本/提交、依赖版本、运行命令和配置；固件/硬件/传感器版本如未知则明确写未知。
- 数据来源（合成/回环/台架/飞行）、会话路径、输入文件来源和必要的哈希；原始日志不修改。
- 时间基准、单位、坐标系、机体/传感器安装朝向、估计器原点与重置情况；不清楚则不做依赖该假设的计算。
- 启止时间、端口/来源、是否还有其他地面站、是否由外部系统预先配置消息流；本工具没有发送请求。
- 观测、预期、偏差、缺测、已知混淆因素；“未收到”不写成“飞控没有产生”。
- 验证等级、未验证项和下一步；禁止把估计值当外部测量真值。

## A. 完全离线：存储和重放

1. 生成小型已知有效 raw JSONL fixture，含正常帧、多个来源、分片/粘连和噪声；fixture 标注为合成，不伪装成真实飞行日志。
2. 执行 replay，验证新建会话四目录、metadata 来源、原始载荷不变、输入文件哈希不变；再重放输出 raw，比较稳定消息字段与统计，忽略新会话路径等运行元数据。
3. 测试非法 Base64、错误字节长度、未知 schema、缺字段、无时区 UTC、索引不递增、单调时间倒退、截断末行；应明确报行号，不覆盖输入，不悄悄跳过。
4. 验证严格 JSON 非有限值编码和未知/缺测语义；禁止 NaN 当正常数值进入均值。
5. 在测试中拦截 socket 创建：replay 应无需网络。只对本机测试环境执行故障注入。

## B. 解析与时间边界

| 输入 | 应检查的现象 | 不得推出的结论 |
| --- | --- | --- |
| MAVLink v1/v2 已知 common 消息 | ID/序号/字段正确，帧字节可追溯 | CRC 正确不表示来源可信 |
| 跨包帧、同包多帧 | 同源正确累计；帧归属完成包 | 接收时间不等于采样时间 |
| 两个 peer 交错半帧 | 状态隔离，不跨源拼接 | 同 IP 不等于同一设备 |
| 坏 CRC/噪声/不支持标志 | parse_error 保留证据，后续帧恢复情况可检验 | 错误计数不等于物理坏包数 |
| unknown message ID | 未知消息显式保留为错误，不计有效消息 | 不宣称验证了未知 CRC_EXTRA |
| 签名帧 | 解析和签名认证区别清楚 | 能解析不表示签名通过 |
| 虚假超长 payload 头/截断尾部 | 检查 pending 与恢复边界 | 不承诺当前实现有超时清理 |
| time_boot_ms、time_usec、SYSTEM_TIME | boot/unknown/unix 分离，alignment null | 不凭数量级猜 UTC，不隐式对齐 |
| 重启/时间回绕 | 保留原值与异常上下文 | boot 时间不保证整个文件全局递增 |

当前 parser 来源数无全局配额；损坏长度导致的不完整候选可能等待后续输入，尚无超时策略。测试应把这些作为已知限制记录，不以“进程没崩溃”替代资源边界证明。

## C. 通信统计

- 构造接收时刻已知的流，验证累计首末窗口频率 `(N-1)/dt`，不是滑动窗口频率；同一包完成多帧时零间隔应可解释。
- 分别覆盖单条、零时长、空采集、稳定周期、停顿、突发聚合；确认 null 不被显示成 0 Hz 实测值。
- 构造序号 `254,255,0,1`、重复、间隙、乱序和模拟重启；验证 modulo-256 启发式。重启/过滤/乱序都可能形成候选缺失，不能输出精确丢包率。
- 混合多消息类型，序号按 peer/SYSID/COMPID 统计而不是按类型拆；频率则按类型拆。
- 心跳间隔仅反映观测到的相邻心跳；单独说明最后一次心跳后的观察时长和未收包情况。

## D. 本机回环：接收路径与零发送边界

仅在明确隔离的 loopback 地址/临时端口运行测试发送器，不向设备 IP 发送。测试发送器属于夹具，不属于产品采集实现。

1. 先启动 capture 并确认监听就绪，再由夹具发送已知帧；检查保存与离线解析一致。
2. 在接收端使用探针或发送 API 拦截，验证 collector/parser/退出路径没有 `send/sendto` 调用，不产生心跳、请求或控制包。
3. 测试端口占用、零数据到期、正常中断和解析异常，检查退出码、summary 状态及文件关闭。
4. 模拟多个来源端口和多个 SYSID，不把会话 `drone` 标签当身份校验。
5. 检查运行时没有 MAVSDK、自动握手或控制进程。网络抓包只能作补充证据，单次未见出包不能代替代码边界和路径测试。

## E. 可选台架/实机观察（未执行）

在另行授权后，只监听由外部预配置的已有遥测。确认本地端口不会抢占操作人员地面站，不修改设备参数，不请求消息速率。先短时采样检查源、坐标、单位、sentinel 和时间域，再决定是否延长记录。

若需要与外部运动捕捉、测距真值或未来 ULog 对照，应独立设计同步实验并量化偏移/漂移/延迟；当前 `clock_alignment=null` 不能支撑毫秒级跨源因果判断。任何飞行动作由独立的人控流程执行，不由实验脚本发送。
